# 🚀 DeZack Portfolio Website

A modern, high-speed solo freelancing portfolio website built with **[Astro](https://astro.build/)** and **[Tailwind CSS](https://tailwindcss.com/)**.

---

## 🛠️ Tech Stack & Architecture
- **Framework**: Astro 5 (Static Site Generation, zero runtime JS overhead)
- **Styling**: Tailwind CSS
- **Contact Form**: Web3Forms (Zero backend, zero Docker, direct email delivery)
- **Deployment**: Vercel / Cloudflare Pages / GitHub Pages

---

## ⚡ Quick Start (Local Development)

1. **Install dependencies:**
   ```bash
   npm.cmd install
   ```

2. **Start the local development server:**
   ```bash
   npm.cmd run dev
   ```
   Open [http://localhost:4321](http://localhost:4321) in your browser.

3. **Build for production:**
   ```bash
   npm.cmd run build
   ```
